## Технологии
- C# и Blazor
- DevExpress Blazor Components
- Entity Framework Core

## Работа с DevExpress
- Для задач с DxGrid используй skill devexpress-blazor-grid.
- Для других компонентов используй соответствующие
  DevExpress Skills, если они доступны.
- При работе с DevExpress API сверяй информацию
  с документацией через MCP-сервер dxdocs.

## Работа с базой данных
- Используй EF Core.
- Следуй существующей архитектуре доступа к данным.

## Работа в песочнице
- запрашивай разрешение сразу на запуск вне песочницы, если работа происходит с бд или браузером.
