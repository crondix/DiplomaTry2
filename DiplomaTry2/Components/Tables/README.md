# DevExpress Grid

События, оба списка принтеров и справочник моделей используют общий компонент
PersistentGrid<TItem, TRow> на DevExpress Blazor 26.1.4. Страница отвечает за
авторизацию и загрузку; RowSelector переводит объекты в типизированные строки
без навигационных свойств EF. Даты и числа сохраняют типы для сортировки и
фильтрации. После загрузки передавайте новый список Items.

GridColumn задаёт заголовок, поле строки, вес начальной ширины и формат.
Имена полей должны быть стабильными. TableKey должен быть уникальным для
таблицы. Label задаёт доступное имя.

LayoutAutoLoading / LayoutAutoSaving сохраняют GridPersistentLayout в
localStorage: ширину, порядок и видимость колонок, сортировку, группировку,
страницу, размер страницы и общий поиск. Строка фильтрации и группировка выключены.
Кнопка «Поиск» раскрывает общее поле поиска по отображаемым колонкам. При скрытии
поиск очищается, чтобы таблица не оставалась отфильтрованной без видимого поля.
После перезагрузки активный сохранённый поиск восстанавливается с открытым полем.
Ключ включает версию схемы, таблицу, хеш идентификатора пользователя и списка
полей. Состояния разных таблиц и пользователей не смешиваются. Настройки
сохраняются после перезагрузки страницы и повторного запуска браузера на этом
же компьютере; синхронизации между устройствами нет. Строки не записываются
в хранилище, но поисковые и фильтрующие значения входят в layout.

Grid создаётся после интерактивного рендера: JS-вызовов на prerender нет.
Повреждённые настройки сбрасываются, отказ в доступе к хранилищу показывается
рядом с таблицей. Кнопка сброса восстанавливает исходный layout.
Кнопка «Колонки» открывает штатный выбор видимых колонок.
В списках принтеров «Очередь» по умолчанию скрыта; «Общее имя» отображается.
После скрытия/показа колонок текущие ширины оставшихся колонок переводятся
в проценты и занимают всю доступную ширину с сохранением пропорций.
При миграции v1 → v2 сохраняются сортировка, порядок и пропорции ширины;
очищаются прежние фильтры, поиск и группировка, чтобы данные не были скрыты
условиями, редакторы которых больше не отображаются.

Заголовки используют штатный NextColumn режим изменения размера. Для границ
в строках grid-state.js отслеживает жесты делегированными обработчиками,
показывает направляющую и передаёт итоговые ширины в .NET. Компонент применяет
их через публичные IGrid.BeginUpdate / IGridColumn.Width / IGrid.EndUpdate
и сохраняет layout. Обработка работает после сортировки и смены страницы.
Минимальная ширина — 64 px. Изменение ширины в строке применяется при отпускании
указателя; в процессе перетаскивания видна направляющая.

Тема Blazing Dark и ресурсы зарегистрированы в App.razor, сервисы — в Program.cs.
Нужен доступный пакет DevExpress 26.1.4 и лицензия DevExpress для сборки и
развёртывания согласно условиям производителя. Секреты NuGet и ключи лицензии
в репозитории не хранятся.

Проверка сборки: dotnet build DiplomaTry2/DiplomaTry2.csproj --no-restore -m:1.
Независимый от БД и Windows-аутентификации браузерный стенд:
dotnet run --project DiplomaTry2.GridChecks --urls http://127.0.0.1:5098.
Стенд использует реальные компоненты, фикстуры и тестовый идентификатор;
он не подключается к БД и серверу печати. Запускать только на loopback.
Автоматическая проверка стенда:
node scripts/test-devexpress-grid.cjs [путь-к-модулю-playwright] [URL-стенда].
Нужны Playwright и Chrome; GRID_TEST_BROWSER позволяет выбрать другой канал.

API: https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxGrid.LayoutAutoLoading
и https://docs.devexpress.com/Blazor/DevExpress.Blazor.GridPersistentLayout.
