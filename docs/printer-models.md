# Модели принтеров

Страница `/PrinterNameVerification` показывает справочник реальных моделей.
Администратор может добавлять модели вручную, редактировать название,
цветность, двустороннюю печать, максимальное количество копий, тип и функции
устройства, технологию и разрешение печати, максимальный формат бумаги,
месячные объёмы и интерфейсы. Удаление требует подтверждения в модальном окне.

Название модели в таблице открывает карточку с группами характеристик по
шаблону `Html/Printer_properties`. Редактирование выполняется в модальном окне.
Плитка «Добавить модели» с иконкой плюса открывает окно ручного добавления и
получения названий драйверов. Выбор источника находится в окне «Настройки».

В режиме редактирования карточки можно загрузить изображение PNG, JPEG или WebP
размером до 2 МБ, увидеть предпросмотр или убрать изображение. Картинка хранится
в БД вместе с моделью и сохраняется только по кнопке «Сохранить». Отмена не
изменяет сохранённую картинку. Общий список не загружает изображения из БД.

Выбор источника на страницах сетевых/сохранённых принтеров, событий и тестовых
страницах также открывается в модальном окне. Главный раздел `/settings`
с настройкой подключений и серверов сохраняет прежний интерфейс.

Кнопка получения названий с сервера печати открывает два списка.
Слева находятся уникальные названия драйверов, отсутствующие в справочнике;
справа — названия, выбранные для создания моделей. Перенос ничего не
сохраняет. Название справа можно исправить. Сохранение выполняется кнопкой
«Добавить выбранные модели». Незаданные характеристики остаются неизвестными.

В `/netPrinters` имя драйвера хранится отдельно от назначенной модели.
Импорт очередей не создаёт модели и сохраняет ручную привязку при повторной
загрузке, в том числе после изменения драйвера. Удаление модели очищает
привязки, сохраняя принтеры и существующие форматы бумаги.

## Обновление схемы

Миграция `20261014000000_PrinterDriverName` добавляет nullable-столбец
`NetworkPrinters.DriverName`. Существующие модели и привязки сохраняются:
их корректность нельзя определить автоматически. Ранее импортированные
универсальные драйверы можно удалить вручную.

После проверки выбранного подключения примените миграции стандартной
командой проекта:

```powershell
dotnet run --project DiplomaTry2/DiplomaTry2.csproj --no-launch-profile -- --migrate
```

Первый импорт после миграции заполнит имена драйверов для существующих очередей.

Миграция `20261014010000_PrinterModelCharacteristics` добавляет необязательные
поля характеристик из HTML-шаблона. Старые записи сохраняются; новые поля
изначально пустые. Рекомендуемый месячный объём не может превышать максимальный.

Миграция `20261014020000_PrinterModelImage` добавляет необязательные поля
изображения и его формата. Данные прежних моделей сохраняются.

## Проверки

```powershell
dotnet test DiplomaTry2.ImportTests/DiplomaTry2.ImportTests.csproj --filter FullyQualifiedName~PrinterModelTests
```

Эти тесты используют SQLite в памяти. SQL Server проверяется только генерацией
SQL миграции и сравнением EF-модели со snapshot, без подключения к серверу.
